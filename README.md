# 📄 사업자등록증 → 엑셀 변환기

사업자등록증(이미지/PDF)을 **비전 LLM** 으로 읽어 **엑셀(.xlsx)** 로 저장하는 Streamlit 앱.
**Ubion LiteLLM 프록시**(OpenAI 호환)를 통해 `gemini-2.5-flash` 로 추출합니다.

## 🚀 설치 & 실행 (Windows)

```bash
setup.bat   더블클릭   → 패키지 설치
run.bat     더블클릭   → 앱 실행 (브라우저 자동 오픈)
```

처음 실행하면 브라우저(`http://localhost:8501`)가 열립니다.

## 🔑 설정 (좌측 사이드바)

앱 왼쪽 **설정**에서 두 가지만 입력하면 끝:

| 항목 | 예시 |
|---|---|
| **프록시 URL** | `http://192.168.50.119:4000/v1` |
| **API 키** | 사내 LiteLLM 키 |

> 비전 모델은 `gemini-2.5-flash` 로 **고정**되어 있습니다 (변경 불가).
> URL·키를 매번 입력하기 싫으면 `.env` 파일에 미리 적어두면 자동으로 채워집니다 (`.env.example` 참고).

## 📤 사용법

1. 사업자등록증 이미지/PDF를 화면에 **끌어다 놓기** (여러 개 가능)
2. **추출 시작**
3. 미리보기 확인 후 **엑셀 다운로드**

## 📊 출력 (엑셀)

- **시트1 `사업자등록증`**: 한 행 = 한 장 (등록번호·상호·대표자·개업연월일·사업장소재지·업태/종목 등)
- **시트2 `사업의종류`**: 업태/종목이 여러 줄일 때 각 줄

## 📁 구성

| 파일 | 역할 |
|---|---|
| `app.py` | Streamlit UI |
| `extractor.py` | LiteLLM 비전 호출 + JSON 추출 |
| `schema.py` | 사업자등록증 JSON 스키마 / 엑셀 컬럼 |
| `imaging.py` | 이미지·PDF → PNG 변환 |
| `excel_writer.py` | 추출 결과 → xlsx |

## ⚠️ 참고

- 추출 결과는 항상 미리보기에서 확인 후 다운로드하세요 (OCR이 100% 정확하진 않음).
- 스캔 해상도가 높을수록(200dpi+) 인식이 정확합니다.
